# Portfolio Website

This directory is reserved for the single-page AI Collaboration Workspace portfolio.

Implementation constraints:

- Use plain HTML, CSS, and JavaScript only.
- Keep Chinese and English copy in locale files under `content/`.
- Treat both locale files as the same content contract; matching keys are required.
- Keep page code separate from copy and evidence metadata.
- Do not copy Skill source files into this directory.
- Add only selected, publication-safe visual exports to `assets/images/`.

Asset groups:

- `assets/images/shared/` — diagrams and visuals used across the page.
- `assets/images/prototype-to-prd/` — publication-safe evidence for the primary case study.
- `assets/images/reference-to-style/` — publication-safe evidence for the supporting case study.

4. Conversational Prototyping
5. Prototype-to-PRD
6. Reference-to-Style
7. Unified Insight
8. Evaluation Principles
