# AI Collaboration Workspace Portfolio Plan

## Portfolio Positioning

AI Collaboration Workspace demonstrates how different task
characteristics require different AI collaboration methods.

The portfolio focuses on designing the boundary between AI capability
and human judgment.

## Collaboration Modes

### Exploration Mode

High uncertainty problems.

Method: Conversation

Example: Conversational Prototyping

### Structured Mode

Multi-stage tasks with independently reviewable outputs and explicit judgment boundaries.

Method: Skill orchestration + Human Gate

Case: PRD Collaboration Agent

Capability path: Prototype-to-PRD Skill → PRD Review Skill → PRD Collaboration Agent

### Creative Mode

Subjective outputs with structured processes.

Method: Skill + Human Evaluation

Case: Reference-to-Style Skill

## Portfolio Principle

The collaboration method changes because the nature of the task changes.
