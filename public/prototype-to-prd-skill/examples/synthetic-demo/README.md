# Synthetic Demo: SproutCircle

This example is entirely fictional. It does not reproduce or adapt any real product, prototype, company rule, or PRD.

SproutCircle is an imaginary household app for tracking when a shared plant was watered. The example shows how the Skill moves from a small prototype to a reviewed PRD without silently deciding ambiguous product behavior.

Read in order:

1. [prototype-input.md](prototype-input.md) — the incoming prototype evidence;
2. [gap-analysis.md](gap-analysis.md) — confirmed behavior, specification gaps, and responsibility routing;
3. [human-gate.md](human-gate.md) — the minimum product decisions and their confirmed answers;
4. [prototype-final.md](prototype-final.md) — the prototype contract after confirmed changes;
5. [prd.md](prd.md) — the final compact PRD.

The demo uses one explicitly fictional pre-existing UI rule to illustrate when AI may resolve a gap without asking the product manager. That rule is evidence for this demo only and is not a default rule of the Skill.
