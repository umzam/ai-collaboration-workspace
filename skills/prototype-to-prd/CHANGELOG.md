# Changelog

## v1.0 — 正式冻结版（2026-08-16）

`prototype-to-prd` 在 Project A / Project B 多轮历史回测与跨项目验证后，冻结为当前正式可使用版本。

### 从最初基线到 v1.0 的主要变化

- 增加证据时点、版本与适用范围判断，避免把过期、局部或未确认信息误当成当前通用规则。
- 优化 Human Gate：已有明确证据或唯一适用的平台规则时直接处理，只把当前决策前沿上无法唯一确定的产品语义交给 PM，减少过度提问。
- 建立根问题优先和条件展开机制：先确认会决定下游方向的根问题，再按确认结果展开依赖问题。
- 优化 PM、平台、数据与技术责任路由：先确定用户可见的产品语义，再评审主键、接口、存储、锁、调度、数据结构等实现机制；混合问题拆分路由。
- 加强正常流程、异常流程、状态转换、失败恢复与边界条件的闭环检查。
- 加强字段、枚举、按钮状态、权限、数据来源、成功条件等开发可实现性检查，确保需求能够被唯一理解。
- 加强 Prototype ↔ PRD 双向一致性及原型实际行为有效性检查，防止只比对页面文案而遗漏真实交互行为。
- 通过 Project A / Project B 历史回测持续修正规则；最终未发现明显的跨项目答案级过拟合。
- 保留可复用的判断方法与稳定机制，不把历史项目的具体业务答案或技术实现固化为通用规则。

验证范围、已知局限和后续版本原则见 `KNOWN_LIMITATIONS.md`。
