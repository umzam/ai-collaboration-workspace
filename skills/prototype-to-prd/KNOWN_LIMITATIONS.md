# Known Limitations — prototype-to-prd v1.0

## 复杂对象生命周期

在复杂业务对象存在多个阶段资格时，Skill 仍可能把以下阶段边界理解得过于合并：

- 可产生
- 可读取
- 可进入人工处理
- 可进入异常修复
- 校验通过
- 可成为正式来源
- 可成为正式结果

这可能导致把“允许进入人工处理 / 异常修复”与“已经具备正式可用 / 正式来源资格”错误地视为同一个阶段条件。

该问题目前只在 Project A 的具体业务中出现，尚未证明属于跨项目通用缺陷，因此暂不继续修改 Core Skill。后续只有在新的真实项目中再次出现类似问题时，才重新判断是否应升级为通用规则。

## v1.0 验证范围

当前 v1.0 已验证于：

- 2 个真实历史产品项目；
- 均属于复杂数据加工平台场景；
- 均包含多页面原型、状态、异常、异步任务及较复杂业务规则。

因此，v1.0 可以作为当前稳定版本使用，但不能宣称已经证明适用于所有类型的产品需求。

## 后续版本原则

v1.0 冻结后，不再因为 Project A / Project B 的单个历史差异继续调整。

只有未来真实项目暴露出新问题，并确认该问题具有可泛化价值时，才允许按以下路径进入下一版本：

真实使用 → 问题记录 → 判断是否通用 → Human Gate → 修改 Skill → Project A / B 回归验证 → 发布 v1.1
